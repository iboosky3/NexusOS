# NexusOS · 纽带

> 面向可扩展自主智能的多智能体编排与 Skill 智能基础设施。

NexusOS 是一套开源 Agent 基础设施，探索当系统拥有上万个 Skill、多个异构 Agent 和大量外部工具时，如何在有限 Token 预算下完成能力发现、任务规划、协同执行与结果评估。

中文名“纽带”表达了系统连接 Agent、Skill、Tool、Memory、Knowledge 与人的定位。当前阶段为架构孵化期，首个验证场景是从产品想法生成结构化 PRD。

## 初始研究范围

- 多智能体任务编排
- 分层 Skill 检索与渐进加载
- 工具协议接入
- 记忆与上下文预算
- 可重复的评估基准
