# Model Gateway

NexusOS 不让 Agent 或工作流直接依赖某个模型 SDK。所有模型调用统一为消息、模型标识、采样参数、最大输出 Token 和审计元数据，并返回内容、实际模型、结束原因和标准化 Token 用量。

## 适配器

- `DeterministicModelGateway`：离线测试，响应稳定且不需要凭据。
- `OpenAICompatibleGateway`：通过标准 HTTP 接入兼容 Chat Completions 的云端或本地模型服务。
- `FallbackModelGateway`：只在超时、429 或 5xx 等瞬时不可用时，按顺序切换到下一个允许当前数据分类的后端。
- 后续供应商适配器：可以支持不同鉴权、工具调用和流式协议，但必须映射回统一结果。

模型路由、降级与预算策略位于 Gateway 之上，Agent 不能通过提示词绕过允许模型、成本上限或数据分类要求。

## 降级规则

`ModelTarget` 同时声明物理模型和允许的数据分类。`restricted` 请求不会为了可用性自动发往只允许 `public/internal` 的云端目标。模型不存在、鉴权失败、请求非法和响应结构错误按永久拒绝处理，立即失败；只有连接失败、超时、429 与 5xx 可以切换后端。

每个目标每次最多尝试一次，禁止在 Gateway 内无界重试。超时发生在供应商已接收请求之后时，切换后端仍可能产生双份计费，因此生产适配器必须携带供应商支持的请求 ID，遥测同时记录每次尝试的供应商、模型、结果和用量。
