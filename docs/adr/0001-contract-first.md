# ADR-0001：核心采用 Contract First

- 日期：2026-05-09
- 状态：已接受

## 背景

第一版计划使用 Python、LangGraph 和本地适配器快速验证。如果领域逻辑直接引用这些实现，后续接入其他 Agent Runtime、向量数据库或多语言服务时会产生大规模改写。

## 决策

领域层先定义任务、Agent、Skill、执行结果与审计事件等稳定模型，并通过端口描述运行时、存储、模型和工具能力。框架与供应商代码只能出现在适配器层。

## 后果

- 核心单元测试可以使用内存适配器，不依赖外部服务。
- 同一工作流可以在不同运行时实现上做对照实验。
- 远程服务拆分时，契约需要增加序列化边界，但领域语义保持不变。
- 开发初期需要维护额外接口，并持续阻止基础设施类型向内泄漏。
