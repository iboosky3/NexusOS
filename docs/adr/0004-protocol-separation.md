# ADR-0004：分离 MCP 工具调用与 A2A 智能体互操作

- 日期：2026-07-19
- 状态：已接受

## 决策

MCP Gateway 只处理工具与资源发现、授权和调用。A2A Gateway 只处理跨 Agent 系统的能力发现、任务委派和状态交换。两者共享身份、策略、审计和可观测基础设施，但不共享业务消息模型。

## 原因

Tool 调用通常是短时、Schema 驱动的动作；外部 Agent 任务可能长时间运行、有独立生命周期和取消语义。混用协议会让授权粒度、错误映射和重试责任不清晰。

## 后果

- Agent Manifest 分别声明允许的 Tool 与外部 Agent 能力。
- MCP 的幂等键不能直接复用为 A2A 任务标识。
- 协议升级可以独立发布。
- 统一 trace 通过关联 ID 连接两类调用。
