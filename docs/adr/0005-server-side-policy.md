# ADR-0005：所有能力调用执行服务端策略

- 日期：2026-08-15
- 状态：已接受

## 决策

Router 可以提前过滤候选，但最终 Tool、Memory、模型和外部 Agent 调用必须由对应 Gateway 使用服务端 Principal 再次授权。策略采用拒绝优先，支持显式人工审批义务。

## 原因

模型上下文可能被 Prompt Injection 污染，客户端字段也可能被伪造。只在提示词中写“不要调用危险工具”不能形成安全边界。

## 后果

- 所有执行适配器接收不可由模型修改的 Principal。
- Policy 决策与执行结果分别审计。
- 高风险动作暂停工作流，不通过静默降级来获得权限。
- 本地规则实现与未来 OPA 适配器必须通过同一契约测试。
