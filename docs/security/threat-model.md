# 初始威胁模型

## 受保护资产

租户数据、模型凭据、Skill 与 Agent 定义、工具权限、Memory、PRD 产物、运行记录和审计证据。

## 主要威胁

- Prompt Injection 诱导 Agent 调用越权工具或泄露上下文。
- 恶意 Skill 在指令中隐藏外部动作或数据提取要求。
- 跨租户 Memory、向量或产物检索。
- 网络重试导致重复写入或支付类副作用。
- Trace、日志和错误消息泄露凭据、提示词或业务正文。
- 供应链依赖或容器以过高权限运行。

## 当前控制

Agent/Skill/Tool 解耦、服务端工具白名单、风险策略、幂等键、租户字段、遥测脱敏、非 root 容器、只读根文件系统和确定性评审阻断。

## 待完成控制

OIDC、工作负载身份、OPA、数据库 Row Level Security、NetworkPolicy、Secret Manager、Skill 签名与来源验证、沙箱执行、依赖扫描和定期恢复演练。

本文是初始模型，不代表完成安全认证。新增协议、存储或高风险 Tool 时必须更新威胁与控制映射。
