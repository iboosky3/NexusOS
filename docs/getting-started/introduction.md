# 项目介绍

## 要解决的问题

传统 Agent 应用常把全部工具和提示词直接注入模型上下文。当 Skill 数量达到数千甚至数万时，这种方法会导致 Token 成本失控、注意力稀释、选择准确率下降和响应延迟上升。

本项目的初始假设是：系统不应让一个模型记住全部能力，而应建立可检索的能力目录，并只在能力真正被选中后加载完整说明。

## 初始目标

1. 把自然语言目标拆解为可执行任务。
2. 从大规模 Skill 集合中检索少量候选。
3. 组织多个专业 Agent 协作。
4. 对上下文、成本、延迟和质量进行度量。
5. 通过 PRD 生成场景验证端到端闭环。

## 非目标

当前阶段不自研大模型推理引擎，也不以替代数据库、消息总线或向量数据库为目标。这些能力通过清晰的端口接入。
