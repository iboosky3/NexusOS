## 选型方向与进行中的改动

用户选择自托管 **GrapesJS 官网开源 Webpage Demo 路线**：以开源 GrapesJS、Webpage Preset 与按需选择的社区插件组合，目标是让插件内的组件和编辑体验更接近官网演示。这与有独立许可证和免费档额度的 Grapes Studio SDK 不同。[官网演示](https://grapesjs.com/demo)、[演示源码](https://github.com/GrapesJS/grapesjs/blob/gh-pages/demo.html)、[Webpage Preset](https://github.com/GrapesJS/preset-webpage)、[SDK 价格](https://grapesjs.com/sdk/pricing)。

Webpage Preset 及基础块、表单、Flexbox、背景样式、导出等开源插件依赖已随 `7d595f1` 提交，经典组件和 Puck 扩充已随 `3607dc6` 提交。提交状态不等于整体验收：此前针对新增表单／提示组件的浏览器拖放回归未通过，不能宣称官网 Demo 功能已经完整嵌入，也不能把 `c00340d` 的通过结果套用到这些新增组件。

后续工作树还加入旧 `/prototype-studio` 的独立浏览器预览入口、预览／编辑切换，以及 Puck 新组件在服务端的模型校验。本轮补齐服务端空白四栏保存的回归测试和类型标注修复；前端类型检查、35 项扩展测试、生产构建与 PRD 原型专项集成测试已通过。真实浏览器端到端预览和新增组件拖放仍待验收。

## 剩余缺口

- 复核官网 Demo 各插件与当前 GrapesJS 版本的兼容性，完成新增组件的真实拖放、保存重开、截图及 PRD 交接回归；逐项记录启用和排除的功能。Webpage Preset 本身并不自动打包全部演示插件。[Preset 说明](https://github.com/GrapesJS/preset-webpage)。
- 目前脚本、外部媒体与任意 HTML 导入受 NexusOS 同源编辑安全边界限制；若要开放此类能力，需要先设计独立隔离和资源协议，不能直接等同于官网公开演示。
- GrapesJS 仍是手工原型插件，尚无 Agent 组件级生成／修改。旧 `/prd-studio` 与 `/studio` 的草稿和交接上下文还未统一；Puck 与 GrapesJS 的同任务编辑效率、性能和真实模型交接尚无并排验收。
- Penpot 尚未集成；是否投入独立部署和设计文件适配，按[选型文档](../architecture/prototype-editor-selection.md)中的触发条件决定。
